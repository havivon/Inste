# Reels Lab

כלי מקומי לצפייה ב-Reels של חשבונות שאתה עוקב אחריהם, עם היכולות שחסרות
באפליקציה של אינסטגרם: **סינון לפי "עוד לא ראיתי"**, מיון לפי צפיות / לייקים /
אחוז מעורבות / אורך, חיפוש בכיתוב, מועדפים, דירוג והערות פרטיות, וסטטיסטיקה
לכל חשבון.

הכל רץ על המחשב שלך: שרת FastAPI מקומי + ממשק דפדפן. שום נתון לא נשלח לשום
שרת חיצוני מלבד אינסטגרם עצמה.

---

## קראו לפני שמתחילים

אינסטגרם **לא מספקת API רשמי** שמאפשר את מה שהכלי הזה עושה. ה-Graph API
הרשמי לא נותן גישה לפיד ה-Reels של חשבון אחר, ולא לשום סימון "נצפה".
לכן הכלי משתמש ב-[instagrapi](https://github.com/subzeroid/instagrapi), ספרייה
שמדברת מול ה-API הפרטי של אפליקציית המובייל.

מכאן נובעות שלוש מגבלות שחשוב להכיר:

1. **זה מנוגד לתנאי השימוש של אינסטגרם.** חשבון שמזוהה כמשתמש בלקוח לא רשמי
   עלול לקבל אתגרי אימות, הגבלות, ובמקרי קיצון השבתה. השתמשו בחשבון בדיקה,
   לא בחשבון הראשי.
2. **"מה שלא ראיתי" נמדד מהרגע שהתקנתם את הכלי.** אינסטגרם לא חושפת בשום
   ממשק — רשמי או לא — אילו Reels כבר צפיתם בהם. הכלי מנהל את הסימון הזה
   בעצמו, מקומית: סרטון נחשב "נצפה" רק אחרי שצפיתם בו **דרך הכלי הזה**, או
   שסימנתם אותו ידנית. בפעם הראשונה כדאי ללחוץ "סמן את התוצאות כנצפו" על
   הארכיון הישן ולהתחיל לעקוב מנקודה נקייה.
3. **כלי צפייה, לא כלי הפצה.** אין כאן הורדה או שמירה של תוכן של אחרים —
   רק צפייה, סינון ומטא-דאטה.

הקצב של הפניות מכוון להיות איטי בכוונה (השהיה אקראית של 2-6 שניות בין
בקשות, עבודה טורית בתור אחד). אל תורידו את זה.

## התקנה

```bash
git clone <this-repo>
cd instagram-reels-lab

python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## הרצה

```bash
python run.py --open
```

הממשק נפתח ב-http://127.0.0.1:8777. בפעם הראשונה תתבקשו להתחבר עם שם המשתמש
והסיסמה של חשבון הבדיקה.

### מצב הדגמה (בלי חשבון בכלל)

```bash
python run.py --demo --open
```

מייצר נתונים מקומיים מזויפים כדי להתנסות בכל הממשק — סינון, מיון, מעקב
צפייה, סטטיסטיקה — בלי להתחבר לאינסטגרם ובלי שום פנייה רשתית. אין וידאו
אמיתי לניגון במצב הזה.

### פתיחה מהפלאפון

השרת ממשיך לרוץ על המחשב; הפלאפון רק מתחבר אליו באותה רשת Wi-Fi.

```bash
python run.py --lan
```

בטרמינל תודפס הכתובת המלאה עם קוד הגישה, למשל:

```
  פתוח גם למכשירים אחרים ברשת. מהפלאפון, באותו Wi-Fi:
    http://192.168.1.14:8777/?token=k3Rm9pQx2Vt
  קוד הגישה: k3Rm9pQx2Vt
```

פתחו את הקישור הזה בדפדפן של הפלאפון. הקוד נשמר בעוגייה, כך שבפעמים הבאות
מספיק `http://192.168.1.14:8777`. הממשק מותאם למסך קטן, וב-נגן אפשר להחליף
סרטון בהחלקה למעלה/למטה כמו באינסטגרם.

שלוש נקודות:

- **בקשות מהמחשב עצמו (localhost) לא דורשות קוד; כל מכשיר אחר כן.** בלי זה כל
  מי שמחובר לאותו Wi-Fi היה מקבל ממשק מלא לחשבון האינסטגרם המחובר.
- **את ההתחברות הראשונה לאינסטגרם עשו מהמחשב, לא מהפלאפון.** התעבורה ברשת
  המקומית היא HTTP לא מוצפן, ואין סיבה שהסיסמה תעבור בה.
- **אל תריצו `--lan` ברשת ציבורית** (בית קפה, שדה תעופה, Wi-Fi של מלון).

הקוד נשמר ב-`data/access_token.txt`. למחזור קוד חדש — מחקו את הקובץ והפעילו
מחדש. אפשר גם לקבוע קוד משלכם דרך `REELS_LAB_TOKEN`.

**בלי התקנה בכלל:** בכרום בפלאפון, `⋮ ▸ הוספה למסך הבית`. מקבלים אייקון ושם
נכונים, אבל זה נפתח בתוך כרום — ההתקנה כ-PWA אמיתי דורשת HTTPS, ומול כתובת
IP מקומית ב-HTTP אין אפשרות כזו.

## אפליקציית אנדרואיד עצמאית

בתיקייה `android/` יש אפליקציה **שלא צריכה את המחשב בכלל**. היא מדברת ישירות
עם אינסטגרם ושומרת הכל במסד נתונים על המכשיר. זו יישום נפרד מהשרת של Python —
שתי הדרכים חיות זו לצד זו ולא מסנכרנות ביניהן.

### איך ההתחברות עובדת

האפליקציה **לא מבקשת ולא שומרת סיסמה.** בהפעלה הראשונה נפתח דף ההתחברות
האמיתי של אינסטגרם בתוך WebView; אתם מתחברים שם כרגיל, ואינסטגרם מטפלת בעצמה
באימות דו-שלבי ובאתגרי אבטחה. כל מה שנשמר אחר כך הוא עוגיית ה-session.

זו החלטה מכוונת: הזרימה החלופית — לממש מחדש את הצפנת הסיסמה של אינסטגרם
בקוד — היא החלק השביר ביותר בכל לקוח לא רשמי, והיא נשברת בשקט בכל פעם
שאינסטגרם משנה משהו. כאן אין קריפטו לתחזק.

מול השרת אנחנו קוראים לאותן נקודות קצה שהאתר של אינסטגרם עצמו קורא להן
מדפדפן מחובר: `users/web_profile_info/` לפרופיל ו-`clips/user/` ל-Reels.

### בנייה

1. פתחו את התיקייה `android/` ב-Android Studio (`Open`, לא `Import`).
2. חכו שיסיים Gradle sync — הוא מוריד לבד את ה-SDK ואת הפלאגינים.
3. `Build ▸ Build Bundle(s) / APK(s) ▸ Build APK(s)`.
4. ה-APK נוצר ב-`android/app/build/outputs/apk/debug/app-debug.apk`.

העבירו לפלאפון ופתחו. אנדרואיד יבקש אישור להתקנה ממקור לא מוכר — צפוי ב-APK
שלא הגיע מחנות.

לפרויקט **אין אף תלות חיצונית** — לא AndroidX, לא ספריות רשת או תמונות. הכל
נשען על ה-SDK בלבד (`HttpURLConnection`, `org.json`, `SQLiteOpenHelper`,
`GridView`, `VideoView`), כדי שהבנייה לא תיפול על גרסאות של ספריות.

### מה יש בה

- התחברות דרך אינסטגרם, מעקב אחרי כמה חשבונות
- סינון: הכל / לא נצפו / נצפו / מועדפים, וחיפוש בכיתוב ובמוזיקה
- מיון: חדש, ישן, צפיות, לייקים, תגובות, אחוז מעורבות, פנינים נסתרות, אורך, אקראי
- נגן מסך מלא: החלקה למעלה לסרטון הבא, למטה לקודם, הקשה לנגן/עצור
- סימון אוטומטי כ"נצפה" אחרי 60% צפייה
- "סמן הכל כנצפה" כדי להתחיל לעקוב מנקודה נקייה
- מועדפים בלחיצה ארוכה על סרטון ברשת

מה שיש בגרסת השרת ואין כאן: סטטיסטיקה וגרפים, דירוג והערות, ייצוא CSV,
ורשימת מילות מפתח להסתרה.

### קצב ובטיחות

כל הפניות לאינסטגרם עוברות ב-thread יחיד עם השהיה אקראית של 2-6 שניות בין
דפים, בדיוק כמו בגרסת ה-Python. סנכרון מושך 3 דפים (כ-36 סרטונים) לכל חשבון.

היתרון של הרצה מהפלאפון: הבקשות יוצאות מכתובת ה-IP הביתית או הסלולרית שלכם,
מאותו מכשיר שבו אתם משתמשים באינסטגרם ממילא — פרופיל תעבורה הרבה פחות חשוד
מאשר שרת.

### דגלים

| דגל | ברירת מחדל | מה זה עושה |
|-----|------------|------------|
| `--host` | `127.0.0.1` | כתובת ההאזנה. |
| `--lan` | כבוי | האזנה גם לרשת המקומית, עם קוד גישה. |
| `--port` | `8777` | פורט. |
| `--demo` | כבוי | נתוני הדגמה מקומיים. |
| `--open` | כבוי | פתיחת הדפדפן אוטומטית. |
| `--reload` | כבוי | טעינה מחדש בשינוי קוד (פיתוח). |

משתני סביבה נוספים: `REELS_LAB_DATA` (תיקיית נתונים), `REELS_LAB_DELAY_MIN` /
`REELS_LAB_DELAY_MAX` (השהיה בין בקשות), `REELS_LAB_FETCH_AMOUNT` (כמה Reels
למשוך בסנכרון).

## מה אפשר לעשות

**סינון**
- לא נצפו / נצפו / מועדפים / מדורגים / מוסתרים
- חיפוש חופשי בכיתוב, בשם המוזיקה ובשם החשבון
- מינימום צפיות, מינימום לייקים, טווח אורך, טווח תאריכים
- רשימת מילות מפתח להסתרה (בהגדרות) — מסתירה אוטומטית כל סרטון שהכיתוב שלו
  מכיל אחת מהן

**מיון**
- החדשים / הישנים ביותר, לפי סדר הגילוי
- הכי הרבה / הכי מעט צפיות, לייקים, תגובות
- אחוז מעורבות `(לייקים + תגובות) / צפיות`
- "פנינים נסתרות" — מעורבות גבוהה ביחס למעט צפיות
- הקצרים / הארוכים ביותר, לפי הדירוג שנתתם, אקראי

**צפייה**
- נגן מלא עם מעבר אוטומטי לסרטון הבא
- סימון אוטומטי כ"נצפה" אחרי אחוז צפייה שניתן להגדיר
- קיצורי מקלדת: רווח, חצים, `W` נצפה, `F` מועדף, `H` הסתר, `Esc` סגירה
- בפלאפון: החלקה למעלה לסרטון הבא, למטה לקודם
- כפתור "נגן את כל מה שלא ראיתי" — תור רציף של כל החדשים

**ניהול**
- מעקב אחרי כמה חשבונות, עם מונה "לא נצפו" לכל אחד
- סנכרון ידני לחשבון בודד או לכולם, עם תור ברקע והיסטוריית סנכרון
- מועדפים, דירוג 1-5 והערות פרטיות לכל סרטון
- ייצוא לכל התוצאות המסוננות ל-CSV או JSON
- מצב כהה/בהיר, ממשק בעברית

## איפה נשמרים הנתונים

הכל בתיקיית `data/` בתוך הפרויקט, ולא נכנס ל-git:

| קובץ | תוכן |
|------|------|
| `reels.db` | SQLite: חשבונות, מטא-דאטה של Reels, מצב צפייה, הערות |
| `ig_session.json` | ה-session של אינסטגרם (הרשאות 600) |
| `ig_username.txt` | שם המשתמש המחובר, לתצוגה בלבד |
| `access_token.txt` | קוד הגישה לכניסה מהרשת המקומית (הרשאות 600) |
| `thumbs/` | תמונות ממוזערות שמורות מקומית |

**הסיסמה לא נשמרת בשום מקום.** היא נשלחת פעם אחת לשרת המקומי כדי ליצור
session, ונמחקת מהזיכרון. למחיקת החיבור: כפתור "התנתק", או פשוט מחקו את
`data/ig_session.json`.

הווידאו לא נשמר — הוא זורם דרך פרוקסי מקומי שמאפשר רק כתובות של ה-CDN של
אינסטגרם, ומרענן כתובת שפג תוקפה.

## תקלות נפוצות

**"החשבון מוגן באימות דו-שלבי"** — הזינו את הקוד מאפליקציית האימות בשדה
"קוד אימות" והתחברו שוב.

**"אינסטגרם ביקשה אימות נוסף"** — בדקו את המייל או ה-SMS של החשבון, והזינו
את הקוד בשדה "קוד אתגר". אם זה חוזר שוב ושוב, החשבון סומן — עצרו לכמה ימים.

**סנכרון נכשל עם שגיאת login** — ה-session פג. מחקו את `data/ig_session.json`
והתחברו מחדש.

**חשבון פרטי** — אפשר למשוך ממנו רק אם חשבון הבדיקה עוקב אחריו ואושר.

**הווידאו לא מתנגן** — כתובות הווידאו של אינסטגרם חתומות ופגות. הכלי מרענן
אותן אוטומטית; אם זה נכשל, הריצו סנכרון לחשבון.
